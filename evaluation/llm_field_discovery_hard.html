B
Hashed / Obfuscated Metric Card (from Experiment 2 · S11)
All class names are CSS-module-style hashes (._3xK9m, ._mNq4w, etc.) that carry no semantic meaning. The LLM cannot infer field roles from class names and must reason entirely from position, tag names, and visible text content. Selectors must use the hashed class names directly — no natural names are available. This is the hardest naming scenario: a field called ._mNq4w should be named metric_name, but the model only sees the hash.
