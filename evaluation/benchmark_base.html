CSS Selector Benchmark Suite

Selector
Evaluation Lab

A static testing ground for evaluating visual scraper selector generation across 14 diverse scenarios — from trivial lists to deeply obfuscated structures. This is the base variant, used to construct scrapers; two further variants (data-changed and mutated) test the survival of those scrapers across realistic page changes.
